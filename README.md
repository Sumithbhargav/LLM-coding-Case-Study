# LLM-coding-Case-Study
# Germany IMF Report Analysis

Analysis of Germany’s 2025 Article IV consultation, published in February 2026.

## Features
- PDF cleaning and summarisation
- Economic indicator extraction
- Single-query and multi-query RAG
- Automated evaluation and dashboard

## Run
1. Open the notebook in Google Colab.
2. Download the assigned PDF from the IMF website. I renamed the downloaded file for use in the notebook; match its filename to `PDF_PATH`.
3. Add `GEMINI_API_KEY` to Colab Secrets and enable notebook access.
4. Run all cells in order.

Outputs are saved in `results/`. Automated findings require checking against the source report.
